# 📂 Velofile – Intelligente Dateiverwaltung

Velofile hilft Ihnen dabei, Ihre Dateien automatisch zu organisieren, Duplikate zu finden und Ihren digitalen Arbeitsplatz sauber zu halten.

---

## 🚀 Installation & Start

1.  Führen Sie die Datei `Velofile_Setup.exe` aus.
2.  Folgen Sie den Anweisungen des Installationsassistenten.
3.  Nach der Installation können Sie Velofile über das **Startmenü** oder das **Desktop-Symbol** öffnen.

---

## 💡 Nutzung

1.  **Regeln erstellen:** Definieren Sie, welche Dateien wohin verschoben werden sollen (z.B. "Alle `.pdf` Dateien in den Ordner `Dokumente`").
2.  **Scan starten:** Velofile analysiert Ihre Ordner basierend auf den Regeln.
3.  **Aufräumen:** Bestätigen Sie die Aktionen, und Velofile sortiert Ihre Dateien automatisch.

---

## 🔐 Lizenz & Aktivierung

Velofile ist eine geschützte Software. Um den vollen Funktionsumfang dauerhaft nutzen zu können, benötigen Sie einen persönlichen Lizenzschlüssel.

### So erhalten Sie Ihre Lizenz:

1.  Starten Sie Velofile.
2.  Beim ersten Start wird Ihnen Ihre individuelle **Machine-ID** (Hardware-ID) angezeigt.
3.  Senden Sie eine Anfrage mit dieser ID per E-Mail an:
    
    📧 **velofile@outlook.de**

4.  Wir senden Ihnen Ihren persönlichen Lizenzschlüssel zurück.
5.  Geben Sie diesen Schlüssel im Programm ein, um Velofile freizuschalten.

> **Hinweis:** Die Lizenz ist an Ihren Computer gebunden und kann nicht auf andere Geräte übertragen werden.
